INK ARCHITECTURE — WEBSITE
==========================
Open index.html in any browser. No installation or build step.
Sections: Home / About / Portfolio / Clients (What People Say + client wall) / Contact.

CONTACT
  A sticky "Message us" WhatsApp button (bottom-right, WhatsApp green) is wired to
  the official number (+91 96633 67649 -> https://wa.me/919663367649) and opens
  WhatsApp with a short prefilled message. The same link also appears in the
  Contact section. (The mailing-list signup has been removed.)

LOOK & FEEL
  Monochrome black & white chrome. Headings Cormorant Garamond; body Jost.
  Hero: framed (white inset border) photo of a contemporary concrete-and-glass
  campus with reflecting pool.
  Portfolio: 3-column mosaic in soft muted colour; full colour on hover; click
  opens a detail view.

FOLDER
  index.html            The website.
  assets/hero/          Hero image.
  assets/projects/      12 project images, named by project.
  logos/                Drop client logo files here (see logos/README.txt).

NOTES
- To change the WhatsApp number, edit the two https://wa.me/<number> links in
  index.html (digits only, country code first, e.g. 919663367649).
- Client wall cells show a monogram + name until a real logo is added at
  logos/<name>.svg, which then replaces the monogram automatically.
- Testimonials quote the firm's own client letters (Skyline Builders, AECOM).
- Instagram/Facebook icons are placeholders (href="#"); only LinkedIn is live.
- Images are full-size for review; compress/serve WebP for production, and
  confirm rights to publish each project image before going live.
- Fonts load from Google Fonts; self-host for production.
