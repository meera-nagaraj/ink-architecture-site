CLIENT LOGOS
============
Real logo files (sourced from clientLogos/) — shown grayscale by default in
the marquee, reveal full color on hover:

  tata-realty.webp   skyline-builders.webp   mariapps.webp   dell-emc.webp
  manhattan-associates.webp   clayworks.webp   mphasis.webp   peninsula.webp
  aecom.webp

If a file goes missing, its slot falls back to a designed monogram + client
name automatically.

Known issue: clayworks.webp is cropped in the source file (cuts off mid-word,
"claywor" + a sliver of "k" — the "s" is missing entirely). Replace with a
complete file when one is available.

Only display logos of clients who have agreed to be shown. Take extra care
with prior-practice projects (Manhattan Associates, Mphasis).
